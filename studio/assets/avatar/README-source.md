# Raft face-following avatar source

Imported from the user-provided `完全版Vtuber.zip` project. The model is `assets/Sitting_Chibi.fbx`; facial layers and viewer modules were copied from the same project. This viewer uses the studio tracking pose and the provided project's face, eye, hair, outfit, and outline rendering.

The source project README states that use and redistribution of model data must follow the original model terms. Keep this notice with the model. Three.js and FBXLoader are vendored from Three.js 0.170.0; see `vendor/three-LICENSE.txt`.
