# たぬつな Studio 0.9.20

## 編集タイムラインを見やすく改善

- 映像レイヤーをV1、V2…、音声レイヤーをA1、A2…で表示します。新規作品と既存作品の両方で2系統ずつを用意します。
- 赤い再生位置バーを見やすくし、表示範囲の外へ移動したときはタイムラインを追従させます。
- トラックの高さと波形の細かさを戻し、波形データはキャッシュして再描画時の負荷を抑えます。
- Vキーの分割で再生位置をまたぐ全トラックを切り、映像と音声の編集を揃えます。対象がない場合は案内を表示します。
- 素材読み込み、末尾追加、再生位置への挿入をボタン名で区別します。同じ素材をもう一度読み込んだ場合も配置でき、追加後は新しい位置へ移動します。
