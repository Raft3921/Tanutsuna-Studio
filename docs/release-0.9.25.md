# たぬつな Studio 0.9.25

## 差分更新に対応

- 前の版と新しい版を比較し、変更されたファイルだけをダウンロードして適用します。
- Macは変更ファイルを反映した一時アプリを作り、置き換え後の起動を確認します。失敗した場合は前のアプリへ戻します。
- Windowsは変更ファイルだけをバックアップして置き換え、起動確認に失敗した場合は元へ戻します。
- 差分パッケージがない版から更新する場合は、完全版を自動で使用します。
- 0.9.24以前のアプリは差分形式を読めないため、0.9.25への最初の更新は完全版を1回適用します。0.9.25以降の更新では変更分のみを取得できます。

完全版ZIPも引き続き配布し、差分更新に対応しない版からの更新と復旧に使います。
