# たぬつな Studio 0.9.10

## 更新処理の修正と進捗表示

- Mac配布ZIPのシンボリックリンクを検証し、アプリ内に安全に収まるリンクだけを許可します。
- macOS標準の`ditto`でアプリを展開し、リンク・実行属性・リソース情報を保ちます。
- 更新のダウンロード、ZIP検証、アプリ展開の進捗をバーと％で表示します。
- Windows更新は通常ファイルのみを安全に展開し、既存の起動確認とロールバックを維持します。

## 最初のインストール

0.9.9以前のMac版は古い更新機能がMacアプリ内のシンボリックリンクを扱えないため、0.9.10を一度だけ手動でインストールしてください。以降はアプリ内更新を利用できます。Windows版は設定画面から更新できます。作品や設定はアプリ本体とは別の場所に保存されています。
