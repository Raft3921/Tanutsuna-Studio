# たぬつな Studio 1.4.0

## タイムライン操作

- 通常のドラッグはクリップ移動を優先し、音量ラインや音量キーの近くからでも配置を動かせます。
- Option（WindowsではAlt）を押しながらドラッグすると、音量ライン・音量キーを調整できます。
- クリップ選択と移動・トリムの判定を整理し、音量調整が意図せず始まらないようにしました。

## V体カメラ

- カメラ追跡をStudioのメインウィンドウ内で動かすように変更しました。追跡開始時に別ウィンドウを開きません。
- カメラ追跡は録画やページ切り替え中もアプリ内で継続し、追跡停止からカメラを終了できます。

Mac・Windows版を作成しました。Windows実機での起動・カメラ・録画動作は未確認です。
