# たぬつな Studio 0.9.22

## 自動編集を分かりやすく

- 無音カットは、声の役割が設定された音声を自動で判定に使います。声の役割がない場合は、タイムライン上の音声を自動で対象にします。素材を選ぶ手間をなくし、必要な場合は判定に使う音を切り替えられます。
- 自動文字起こしは、自分の声を優先して自動選択します。声の役割がない場合は先頭の音声を選びます。
- モデル取得・音声準備・文字起こしの進行状況を画面に表示し、起動や処理に失敗した場合も理由を確認できるようにしました。
- 生成された仮テロップは確認・編集後にタイムラインへ追加し、字幕ライブラリにも保存できます。

文字起こしの初回利用では、選択した音声認識モデルをダウンロードします。音声データはPC内で処理し、文字起こしのために外部へ送信しません。
