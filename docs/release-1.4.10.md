# たぬつな Studio 1.4.10

## Windows収録

- PC音のWASAPI録音ヘルパーが連続する音声パケット処理で停止信号を見落とす可能性を修正しました。
- 停止中は、画面映像とPC音のどちらの確定を待っているか表示します。
- `capture.log`にヘルパーの開始・停止・RF64確定状況、`finalization.log`に各停止段階と期限切れ時の状態、`compiler.log`にコンパイラ利用状況を記録します。
- 停止期限に達した場合、取得済みPC音のRF64ヘッダー修復を試みます。音声変換に失敗しても、正常な画面映像と他の素材を保存し、元音声を残します。

## 対応環境

- macOS Apple silicon
- Windows 11 x64

Windows実機でのPC音収録・停止動作は、このビルド環境では未確認です。
