# たぬつな Studio 1.7.1

## 起動時エラーを修正

- 配信画面の `QPointF` 読み込み元を修正し、Macアプリ起動時に表示されるImportErrorを解消しました。

## 配信画面をゲーム風に刷新

- オープニングにNOW LOADING風のHUDと進捗演出を追加しました。
- 離席中はBRB表示、経過時間、マイクの自動ミュート状態を表示します。
- 配信の背景を暗色ハーフトーンにし、シーン切替をネオンのジグザグワイプへ変更しました。
- シーン選択を説明付きのカードUIに変更しました。
- 配信画面へ暗色のLIVE CHATパネルと接続状態を表示します。チャット接続にYouTube APIキーは不要です。

## 滑らかさと追従を改善

- 配信映像の合成とV体更新を60fps目標へ変更し、配信モニターへ合成fpsを表示します。実際のfpsはPCの処理性能と描画バックエンドにより変わります。
- ラフトのカメラ追跡結果に左右の瞬き値を追加し、V体へ渡すよう修正しました。
- 短い瞬きを取りこぼしにくいよう、カメラ推論を約25〜30fpsへ調整しました。
- 配信プレビューは約30fpsで更新し、プレビュー縮小処理による合成負荷を抑えます。

## 対応環境

- macOS Apple silicon
- Windows 11 x64

このリリースでは実機の配信・全端末での実測fpsは確認していません。配信モニターのfps表示で動作中の合成速度を確認できます。
