# たぬつな Studio 1.4.4

## Windows版の名前とアイコンをStudio用に統一

- Studio独自のたぬきアイコンを追加し、ウィンドウ、タスクバー、スタートメニューのショートカットに使います。
- Windowsのアプリ識別子と表示名をStudio用に設定し、Pythonの名前でグループ化・表示されにくくしました。
- インストール後のショートカット名を「たぬつな Studio」に統一します。

## 対応環境

- macOS Apple silicon
- Windows 11 x64

Windows実機でのインストール後のタスクバー表示はこの配布物の作成環境では確認できていません。
