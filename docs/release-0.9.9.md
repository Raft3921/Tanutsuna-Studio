# たぬつな Studio 0.9.9

## V体カメラの起動修正

- カメラとマイクを同時に使う時のQt WebEngine許可要求を処理します。
- macOSのアプリ単位カメラ許可をカメラ追跡開始時に確認し、未確認ならOSダイアログを表示します。
- カメラが拒否・未接続・他アプリ使用中の時に、原因と対処の案内を表示します。
- 録画の自動準備でも許可待ち・拒否状態が録画画面に伝わり、原因不明の「Invalid state」だけで止まらないようにします。

## 更新

アプリの設定画面から最新版を取得できます。0.9.7以降はアプリ内更新に対応しています。0.9.6以前は更新機能を含む版を一度手動で導入してください。
