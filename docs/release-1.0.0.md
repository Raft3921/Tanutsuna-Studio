# たぬつな Studio 1.0.0

## バージョン番号を1.0.0へ

- バージョン表記を `1.0.0` に改めました。以降は修正でパッチ番号、機能追加でマイナー番号、大きな仕様変更でメジャー番号を進めます。

## 更新のダウンロードを高速化

- 完全版ZIPは最大8接続のHTTP範囲ダウンロードに対応しました。未対応の配信元では自動的に従来の単一接続へ切り替えます。
- 0.9.25からは差分更新を使い、変更ファイルだけを取得します。SHA-256検証と起動失敗時の復元は維持します。
- 0.9.25からは1.0.0への差分ZIPを利用できます。0.9.24以前は差分更新に対応していないため、1.0.0への移行時に完全版を一度ダウンロードします。旧版は単一接続で取得するため、回線が遅い環境では時間がかかる場合があります。1.0.0以降は完全版も最大8接続で並列取得し、前の版に対応した差分ZIPがある場合はそちらを優先します。
