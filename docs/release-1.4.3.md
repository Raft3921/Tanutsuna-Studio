# たぬつな Studio 1.4.3

## V体カメラ追跡の状態を分かりやすく

- カメラを起動しただけで「追跡中」と表示せず、準備中・顔を探しています・顔を検出中を区別します。
- 顔を検出できないときは追跡ページからの状態をV体画面に表示します。
- カメラ許可が拒否された場合は、Windowsのカメラ設定で確認する項目を画面に案内します。
- 顔の向きは小さな変化も確認できるよう、角度表示を小数点第一位まで表示します。

## 対応環境

- macOS Apple silicon
- Windows 11 x64

Windows実機でのカメラ追跡はこの配布物の作成環境では確認できていません。
