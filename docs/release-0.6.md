# Tanutsuna Studio 0.6 — 企画から収録・編集へ

「新しい企画を作成」から始め、予定、色・文字サイズ・太字を使うメモ、色と太さを選ぶペンボードにアイデアを残せます。「企画の概要」にゲーム、ジャンル、内容、必要なものをまとめ、同じ企画名で収録へ進みます。メモはプロジェクト内の `00-plan/plan.json` へ自動保存します。別の企画への切替・終了前にも保存し、保存失敗時は切替を止めてメモを保持します。

収録は「2 収録」、編集は「3 編集・仕上げ」にまとめました。V体の詳細設定は左下と収録画面にあります。V体を有効にして収録を開始すると、カメラを裏で起動して顔の検出を待ちます。初回のOS許可はユーザー操作が必要です。60秒以内に準備できなければ収録を始めず、設定の確認を案内します。「準備を中止」でも終了できます。アプリが自動で開始したカメラは収録終了後に止めます。

赤い「● 収録中」と経過時間をヘッダーと収録画面に表示します。停止後は元データを確保して変換し、映像・PC音・声・V体を同期して編集へ配置します。続きの収録も右端へ追加します。文字起こしとゆっくり音声生成は画面と自動処理から削除しました。過去の素材を消すことはありません。
