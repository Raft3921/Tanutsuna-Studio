# たぬつな Studio 1.1.0

## プレビューから素材を選択

- プレビュー上の映像やテロップをクリックすると、そのクリップをタイムラインとインスペクターで選択します。
- 再生位置を動かすと、その位置にある一番上のクリップが標準の編集対象になります。タイムラインやプレビューで別のクリップを選ぶと、そのクリップを優先します。

## かんたんインストーラー

- 最初に取得するインストーラーZIPは小さく、展開後にOS別の手順を表示します。
- Mac・Windowsとも最大8接続で完全版をダウンロードし、進捗とSHA-256を確認してから配置します。
- Macインストーラーは配置したアプリの隔離属性を処理します。初回のみインストーラーをcontrolクリックして「開く」を選んでください。
- Windows版はユーザー領域へ配置し、スタートメニューにショートカットを追加します。
- 完全版ZIPもReleaseに残しているため、従来の手動インストールも選べます。
