# たぬつな Studio 0.9.12

## 動作の軽さと起動時の見やすさ

- 編集画面を開いている間の素材チェックを毎秒繰り返さないようにし、作品を開いたときに確認します。
- タイムラインの波形描画を軽くしました。
- ライブプレビュー停止中は描画タイマーを止め、プレビュー中のV体描画は30fpsで更新します。配信出力は60fpsのままです。
- 収録中のV体動きデータをファイルへ書き出す頻度を下げました。
- V体の顔や耳が枠外へ出にくいよう、描画範囲を広げました。
- 起動処理中に「起動しています…」と表示します。

作品・素材・設定は従来どおりアプリ本体とは別に保存されます。
