# たぬつな Studio 1.8.2

## チャットの配信表示

- チャット読み込み用に画面のないWebページを使わず、チャットタブに表示するYouTube画面からメッセージを取得します。
- チャットを有効にすると確認用のチャットタブへ切り替わります。配信映像には、取得したメッセージを独立したオーバーレイとして合成します。
- 送信メッセージがまだない時も配信映像内に待機パネルを表示し、読み込み済みとメッセージ取得済みを分けて示します。

## 配信映像内のUI

- ロード画面、離席画面、シーン切替、チャットを明るい色とドット調の線・背景で統一しました。

## 確認状況

- Python構文とMacアプリ・Windows配布物のビルドを確認しました。YouTube実配信でメッセージを投稿した状態の確認は行っていません。
