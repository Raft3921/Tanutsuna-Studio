# たぬつな Studio 1.3.0

## 複合クリップの自動処理

- 無音カットで複合クリップを選ぶと、内部の音声クリップを解析し、複合クリップ上の時刻に反映します。
- 自動文字起こしで複合クリップを選ぶと、内部の音声をタイムライン位置に合わせてミックスして認識します。
- 入れ子になった複合クリップも解析対象です。

## プレビューから直接変形

- プレビュー内の素材をクリックして選択し、中央をドラッグして移動できます。
- 四隅と上下左右のハンドルでサイズを変更できます。通常は縦横比を固定し、Shiftを押しながらドラッグすると縦横比を別々に調整します。
- 素材の上にある回転ハンドルをドラッグして角度を調整できます。
- 変形は編集データに保存され、元に戻す操作にも対応します。

編集の保存・変形・音声解析は未署名のMacビルドで確認中です。Windows実機の起動・編集は未確認です。
