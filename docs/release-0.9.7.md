# たぬつな Studio 0.9.7

## GitHubからの更新

- 起動時にGitHub Releasesの最新版をバックグラウンドで確認します。
- 設定画面の「更新を確認」から手動でも確認できます。
- 更新は別プロセスで取得し、ReleaseのSHA-256、ZIPの整合性、対象OS、内包アプリの版数を検証します。
- 検証済みファイルを一時領域へ展開してから、設定画面の「更新して再起動」で適用します。
- 更新版が起動したことを確認してから旧版を削除します。起動確認に失敗した場合は旧版へ戻して起動します。
- 録画、配信、素材処理、編集の保存中は更新を適用できません。
- ユーザーの作品・設定はインストール先と別のユーザーデータ領域に保管します。

## 配布方法

`main`ブランチにはソースコードを置きます。自動更新ではGitHub ReleasesのOS別ZIPを使用し、版数タグを付けて以下のファイル名で公開します。

- `Tanutsuna-Studio-macOS-arm64.zip`
- `Tanutsuna-Studio-Windows11-x64.zip`

初めて自動更新機能を使うときは、0.9.7以降のアプリを一度インストールしてください。0.9.6以前には更新確認機能がないため、初回だけ手動で更新します。

## 対象

- Mac：Apple Silicon、macOS 15以降
- Windows：Windows 11 x64

自動更新は上記の配布版向けです。ソースから起動した開発環境ではアプリ本体を置き換えません。
