# たぬつな Studio 1.6.1

## 視線と口の修正

- ラフトV体がカメラの虹彩を追従するようにしました。「正面を基準にする」で視線も中央に合わせます。
- 口の母音判定を完全版Vtuberと揃え、母音画像の形をそのまま表示するようにしました。

## ラフトV体の描画を修正

- 1.5.10で起きていた、ラフトV体のプレビューが表示されない問題を修正しました。
- 顔画像の読み込み中も仮テクスチャで初期描画を続け、目や口の範囲が未設定のまま描画処理を止めないようにしました。
- Qtの表示領域サイズをThree.jsへ渡し、0×0のWebGLキャンバスから復帰できるようにしました。
- 透過PNGをQtへ渡す際の読み込み形式を修正しました。
- V調整画面でラフトV体を選び、髪・顔・衣装を含むモデルがプレビューへ表示されることを確認しました。

## 対応環境

- macOS Apple silicon
- Windows 11 x64

この環境ではWindows実機での描画は確認していません。
