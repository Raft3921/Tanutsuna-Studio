# たぬつな Studio 0.9.14

## 自動文字起こしとテロップ

- タイムライン上の音声素材を選び、WhisperでPC内処理の文字起こしができます。音声データは外部へ送信しません。
- AIモデルは初回利用時に選んでダウンロードします。配布ZIPには含めず、アプリ本体の容量を抑えています。
- 1枚あたりの文字数・単語数・改行を設定し、文章を確認・修正してから仮テロップを配置できます。
- 生成字幕は字幕ライブラリにSRT形式で保存され、後から再利用できます。配置した字幕をまとめて選び、登録済みのテロップデザインを適用できます。

## 編集操作

- 無音カットに「ゆったり」「おすすめ」「テンポ重視」の設定を追加しました。解析後に結果を確認してから、映像・音声・V体を同期してカットできます。
- テロップのモーション設定に、位置・大きさ・角度のスライダーを追加しました。プレビュー上のドラッグによる位置調整も使えます。

## 注意

- 文字起こし速度と認識品質はPCの性能、音質、選択したモデルによって変わります。認識結果を確認してから字幕を配置してください。
- モデルの初回ダウンロードには、モデルに応じて約190〜574 MBの通信量と保存容量が必要です。
