# たぬつな Studio 1.1.1

## ライブ配信の安定性を修正

- macOS版でライブ配信時にV体カメラ追跡の画面を開くとアプリが強制終了する問題を修正しました。
- QtWebEngineのカメラ追跡プロセスに必要なmacOS権限を付けて署名し、GPU自動切り替えに対応しました。
- V体を重ねない設定では、従来どおりカメラ追跡を起動せずに配信できます。

## インストール

- 小型インストーラーまたはMac/Windowsの完全版ZIPを使用してください。
- Mac版はApple Developer IDで公証したアプリではありません。初回起動時にmacOSの警告が出る場合は、インストーラー内の案内に従ってください。

Windows実機での配信・カメラ動作は未確認です。
