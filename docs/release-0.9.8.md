# たぬつな Studio 0.9.8

## V体の発話中の口の動き

- 口の形をカメラの顔認識だけでなく、マイクの音量でも補助します。小さな発話でも口が閉じたままになりにくくしました。
- マイクの感度をカメラトラッカー内で調整できます。雑音で口が動く場合は感度を下げてください。
- 使うマイクを選べます。選択したマイクは次回も記憶します。
- 音声と映像はPC内だけで処理します。音声データは配信先やインターネットへ送信しません。
- マイクを使用できない場合は、顔の口形だけで追跡を続けます。

## GitHubからの取得・ビルド

Macでは [`最新版を取得してビルド.command`](../最新版を取得してビルド.command) をダブルクリックし、最新版の取得とMac/Windows用配布物の作成を選べます。未保存のソース変更がある時は更新を止め、変更を失わないようにします。

アプリ本体の更新は設定画面から行えます。0.9.7以前は0.9.8を一度手動でインストールしてください。
