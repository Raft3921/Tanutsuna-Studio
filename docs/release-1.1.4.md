# たぬつな Studio 1.1.4

## 自動文字起こしと仮テロップを改善

- Whisperの単語・認識単位ごとの時刻から字幕を作り、無音や発話前に字幕が出にくいようにしました。
- 文字数・単語数・改行設定を変更した後に、文字起こしをやり直さず字幕の区切りを再適用できます。
- 字幕一覧で開始・終了時刻と文章を直接修正できます。選択した字幕の開始時刻へプレビューを移動できます。

## 編集操作を改善

- 字幕のタイミングを確認しながら調整し、選んだものだけ、または全てをタイムラインへ追加できます。
- 追加した字幕はタイムライン上で複数選択し、デザインをまとめて変更できます。

Windows実機での文字起こし・字幕表示は未確認です。
