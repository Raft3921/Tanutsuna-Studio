# Tanutsuna Studio 0.7 — 無音カット・音量・BGM

企画→収録→編集の流れに、編集画面の「自動編集」メニューとツールバーを追加しました。

## 無音カット

「無音カット」を開き、収録の声（自動識別）、または配置済みの音声クリップを指定します。無音の音量基準、最小の長さ、言葉の前後に残す余白を設定して解析します。区間数と短縮時間を確認し、「同期カットを適用」を押します。

画面・PC音・声・V体・BGMを含む全トラックの同じ区間を切り、後ろを前に詰めます。元ファイルは変更しません。移動・トリミング後の素材も、編集で使用中の範囲を解析します。複数の声が重なる場所では、解析対象のどれかに声がある区間を残します。音量・ミュートの設定前の元音声を解析します。

映像と音を一つに扱うには、複数クリップを選択し「選択した映像と音をまとめる」を使います。その複合クリップの中を開いて無音カットを実行できます。短縮は同じ複合クリップを使用する親の編集版にも同期して反映します。音量と位置のアニメーションを保持し、編集の「元に戻す」で取り消せます。

## 音量・BGM

「音量・BGM」で、素材ごとに「自分の声」「ゲーム・PC音」「効果音・追加音」「BGM」を指定します。収録した声・ゲーム音は自動識別します。BGMの役割はMP3音声に指定できます。

全体音量は現在の音量へ掛ける割合（0〜100%）です。100%なら維持、50%なら半分です。声100／ゲーム40／効果音75／BGM20のプリセットもあります。既存のフェードとミュートを保持し、現在の編集版とその複合クリップに適用します。素材の役割は保存され、別の編集版の音量は変えません（同じ複合クリップを共有する場合、その中の編集は共有されます）。

BGMタブで複数のMP3を候補に追加できます。候補はプロジェクトへコピーして保存し、この時点ではタイムラインに配置しません。追加後にもう一度「音量・BGM」を開いて一曲を選ぶと、先頭から専用音声トラックへ配置します。現在の編集版の旧BGMを入れ替えます。曲が動画より短い場合は曲の終端までです。「維持」「BGM配置を外す」も選べます。

## 確認範囲

無音解析の実FFmpeg処理、全トラックの同期、移動・トリミング後の処理、複合クリップの親への反映、音量の保存と取り消し、BGM候補の未配置保存など9件と、既存収録7件を確認しました。まとめた収録やカット済み素材を開き直して元の素材を二重配置する問題も対策しました。

Mac・Windowsの配布物を更新します。Windows実機、実カメラの新しい自動起動経路、長時間収録・長尺素材の性能は未確認です。MacはApple Silicon/macOS 15以降向け・未公証、WindowsはWindows 11 x64向け・未署名です。
