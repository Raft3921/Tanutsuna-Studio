# たぬきV体：モデル改訂 0.5

ユーザーが提示したサングラス姿のイラストを基準にした、手足・鼻のない丸いたぬきです。「光沢」の文字と矢印は図の注記として扱い、モデルには加えていません。

- 口元は鼻や別々のひげを足さず、中央から左右へ流れる一本の線で構成。端を丸めています。
- 口は赤いしずく形。頭部メッシュに実際の開口を作り、縁と奥のある口腔を設けました。開きに加え、あいうえお別に横幅と高さを調整できます。口の縁は各フレームで再構成し、開閉の途中も断面の半径を保ちます。
- 目は凸面レンズ上のUVテクスチャとして固定。まばたき、目線、白目、眼球の可動はありません。
- 耳は縁から内側のくぼみまで連続する形状。丸みのある輪郭と内耳の折り返しを設けています。
- アウトラインは反転した外殻メッシュ。表示は3段階のトゥーンシェーディングです。ゴーグルには一定幅の薄いフレームと凸面レンズを設けています。サングラスの光沢の帯はテクスチャに描いています。
- 顔と耳の外殻、ゴーグル正面、口元の線は共通の基準幅0.042で太めに統一しています。
- 手足、鼻、青髪はありません。

## 操作

制作デスクの「2. V体」または「V体を動かす」タブから操作します。

カメラ追跡は顔の向き、位置、口の開閉を使用します。初期値は向き1.7倍、移動1.3倍、口2.0倍。「今の向きを正面に」で姿勢を合わせ、倍率を調整できます。耳の小さな揺れは補助アニメーションです。全身や手足の追跡はありません。

カメラはソフト内の補助画面で開始・停止します。Qt WebEngineとMediaPipeランタイムを同梱し、外部ブラウザを開かずPC内で処理します。閉じるとカメラ入力も停止します。顔の生映像をモデル出力画面には表示しません。

0.5では上下反転を修正。GPU表示はステンシルで顔・耳の表面を保護し、切り抜きのない連続した外殻を外周だけに表示します。互換表示も外殻を先に描きます。形状を63,976から26,596三角形へ削減し、口と開口周辺のみ現在の口形に合わせて頂点を更新し、GPUで描画します。追跡の推論間隔は50ms、カメラは480×360・24fpsを希望値として取得します。カメラ処理用エンジンはカメラ画面を初めて開く時だけ起動します。

## ファイル

- `studio/assets/tanuki/tanuki.blend`：編集可能なBlenderソース。テクスチャを内包。
- `studio/assets/tanuki/tanuki.glb`：骨組み、口の変形、テクスチャ、反転外殻を含む交換用モデル。
- `studio/assets/tanuki/tanuki_basecolor.png`：体のベースカラーテクスチャ。
- `studio/assets/tanuki/goggle_lens.png`：レンズと光沢のテクスチャ。
- `studio/assets/tanuki/tanuki.mesh.json.gz`：同じモデルをネイティブ表示するためのランタイムデータ。
- `scripts/build_tanuki.py`：形状・UV・素材・可動部を再生成するBlender用スクリプト。

再生成コマンド：

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python scripts/build_tanuki.py
```

GLBは外部ビューアでも色を保つため `KHR_materials_unlit` を使用します。アプリ本体とBlenderソースでは3段階の陰影を付けます。GLBの外部ビューアによってアウトラインや表情の操作方法が異なります。

## 確認範囲

Blenderで正面と斜めからの見た目を確認。Mac上のQt OpenGL表示、モデルの骨・口の変形、ローカル追跡通信、追跡信号の失効を確認しました。カメラエンジンは模擬カメラの開始・停止と、公開テスト写真での推論を確認しています。本人の実カメラでの動きの調整とWindows実機確認は残っています。

旧版で作った `script.txt` は削除していません。現在の「2」は台本ではなくV体操作です。

## 口形調整（制作デスク0.5）

「V体」の「あいうえおの口形」で各母音を選び、横幅と開いた時の高さを設定します。手動モードの「口を開く」で中間形も確認できます。「口の線の太さ」は下唇の縁に共通で適用します。設定は自動保存され、動きの記録にも反映します。カメラ入力の母音は唇の開き・横への広がり・すぼめからの推定で、音声の母音認識ではありません。

調整はアプリのプレビューと収録した透過映像へ反映されます。交換用GLBは従来のjawOpenを保持し、アプリ側の母音調整値は含めません。
