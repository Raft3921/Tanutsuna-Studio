# たぬつな Studio 1.1.3

## 録画・ライブ配信の起動を修正

- Mac版にNumPyとimageio-ffmpegを同梱し、V体描画や録画画面の初期化で必要なモジュールが見つからない問題を修正しました。
- 配信画面は、ゲームウィンドウ未選択時に映像確認・配信開始を無効にし、必要な操作を案内します。
- 映像プレビューはYouTubeキーなしで利用できます。実際の配信開始には、ゲームウィンドウとYouTube Studioのストリームキーが必要です。

## インストール

- アプリ内の更新、または小型インストーラーを利用してください。
- Windows実機でのライブ配信、カメラ、動画編集は未確認です。
