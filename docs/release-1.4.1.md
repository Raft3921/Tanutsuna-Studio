# たぬつな Studio 1.4.1

## プレビュー変形

- 選択中の素材のハンドルを他の重なった素材より優先して掴めるようにしました。
- ハンドルを大きくし、近づけた時のカーソル表示を追加しました。

## タイムライン

- 映像トラックを68px、音声トラックを44pxに整理して、縦に見渡せる範囲を広げました。
- 音声クリップ名を常に表示し、動画サムネイルと音量波形の重なりを抑えました。

## 自動文字起こし

- Whisperの制御トークン（`[_BEG_]`、`[_TT_192]`など）が仮テロップへ混ざらないよう除去します。
- 日本語モードで母音のローマ字誤認識をかなへ整え、例の「かきくけこ」の誤変換も補正します。

Windows実機の表示・操作・文字起こしは未確認です。
