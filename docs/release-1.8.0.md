# たぬつな Studio 1.8.0

## 配信の安定性と音声

- 配信送出キューが混み合った時、映像・音声を個別に間引かず、送出を再接続して時刻同期を取り直すようにしました。
- 送出キューの混雑による再接続理由を配信画面に表示します。

## チャット・オープニング

- チャットページの読込完了と、配信映像への取り込みを区別して表示します。取り込めた状態を「CHAT IN PROGRAM」と表示します。
- オープニングに提供GIFを使い、シーンを手動で切り替えるまでループします。オープニング中はV体を隠し、マイク・PC音・BGM・効果音をミュートします。
- オープニングから配信シーンへ切り替えた後に映像・音声を有効化します。

## V体の口の動き

- 母音の口形を閉じた口を挟まず直接補間します。短い無音や追跡の揺れで口が頻繁に閉じないようにしました。

## 対応環境と確認状況

- macOS Apple silicon
- Windows 11 x64
- ソースの構文確認を実施しました。実配信での回線・機器別の確認は行っていません。配信モニターの実測fpsと音声メーターを確認し、回線や負荷に応じて720p/60fpsを選択してください。
