# たぬつな Studio 1.4.6

## 設定の保存

- 録画の画面・マイク・音声・V体設定を自動保存し、次回起動時に復元します。
- 配信の画質、ウィンドウ、マイク、V体の位置と大きさ、音量とミュート、BGM、同時録画設定を自動保存します。
- YouTube配信URLを入力後に保存し、APIキーとストリームキーは保存を有効にするとOSの資格情報ストアへ保存します。

## Macの画面収録許可

- Mac版をApple Development証明書で固定署名し、Macの自動更新では署名済みの完全版アプリを使います。更新のたびに仮署名を作り直す処理を避け、画面収録許可を維持しやすくします。
- 仮署名版からこの版へ切り替えると、macOSが一度だけ画面収録の再許可を求める場合があります。
- Mac版はApple Developer IDによる公証を行っていません。初回インストール時はインストーラーの案内に従って開いてください。

## 対応環境

- macOS Apple silicon
- Windows 11 x64

macOSの画面収録許可が更新後も保持されるか、実機での連続アップデート確認は行っていません。Windows実機での動作も未確認です。
