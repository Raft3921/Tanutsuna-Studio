# たぬつな Studio 1.2.0

## 起動時の更新確認

- 起動時にGitHub Releasesをバックグラウンドで確認します。
- 更新が見つかると画面上部に版数付きのボタンを表示し、どの画面からでもダウンロードを開始できます。
- ダウンロード中は進捗を表示し、完了後は同じボタンから再起動して更新を適用できます。
- 従来どおり設定画面の更新操作も利用できます。更新を後回しにしても、ボタンからいつでも再開できます。

## 水色を基調にしたデザイン

- 画面背景、ナビゲーション、カード、入力欄、選択状態、進捗表示を空色と青緑の配色に統一しました。
- 文字の読みやすさと操作状態の見分けやすさを保ちながら、たぬつならしい軽やかな見た目にしています。

アプリの更新は録画・配信・素材処理を妨げず、適用前に編集内容を保存します。Windows実機での表示・更新動作は未確認です。
