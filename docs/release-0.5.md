# たぬつな Studio 0.5 — 保存と口形の改訂

## 使い方

WindowsはZIPをすべて展開し、Tanutsuna Studio.exeを開きます。MacはTanutsuna Studio.appを開きます。既存の動画と収録データをそのまま使用できます。

「V体」→「手動で可動確認」で、「あいうえおの口形」の母音を選びます。横幅と開いた時の高さを母音別に調整し、「口を開く」で中間の形も確認できます。口の線の太さは下側の縁に共通で適用します。変更は自動保存されます。「可動テスト（自動）」では5種類を順番に動かします。カメラでは唇の形から母音を推定します。音声認識による厳密な母音判定ではありません。

「収録・音声」で「V体も別素材に保存」を有効にし、収録後に「停止して保存」を押します。収録済みの元データを確保し、MP3・透過V体映像をまとめて保存してから編集へ配置します。透過映像の変換には収録の長さに応じて時間がかかります。変換中は進捗を表示します。文字起こしは素材保存後に始まります。

保存や変換が中断した場合は、動画を開き直し、収録を選んで「未完了の整理・映像化を再開」を押します。V体の変換が失敗しても画面映像・元音声・動きデータを保持します。「V体を高画質・透過で作り直す」で現在の描画方式による再生成もできます。過去の収録の口形は収録時の動きを使用します。

## 修正の根拠と確認範囲

- Macの直近4件のクラッシュ記録は、Qtのアプリ全体のイベントフィルターがネイティブオブジェクトをPythonへ渡す処理で一致。編集画面からこのフィルターを除去し、キーイベントと既存のアクションで操作を継続。
- 変換失敗時に収録フォルダを破棄していた処理を変更。収録後の元データを先に確保し、各素材の確定ごとに収録情報を保存。
- 準備の中止分は破棄し、収録開始後の失敗・中断分は復旧用に保持。復旧対象は一覧に表示。
- 口の縁の形を線形補間する方式から、現在の開き・幅・高さで断面を再生成する方式へ変更。閉じた口角を含め、線の太さを維持。
- MacのQt GPU描画で5回連続のV体保存・編集配置・ネイティブウィジェット破棄を確認。49件の自動テストを確認。

Windows実機、本人のカメラでの口形調整、長時間のゲーム同時収録は未確認です。Mac版は未公証、Windows版は未署名です。低スペック機での50fps維持や変換速度には機器差があります。
