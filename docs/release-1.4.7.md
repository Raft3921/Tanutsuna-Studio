# たぬつな Studio 1.4.7

## ライブ配信

- チャット欄を右側パネルから外し、配信プレビュー上に重ねて表示できるようにしました。初期状態はオフです。
- YouTube配信URLだけでチャットを表示できます。チャット自体にYouTube Data APIキーは使いません。視聴者数取得用のAPIキー入力欄はライブ画面から外しました。
- カメラを追跡モデルの読み込みより先に起動します。カメラアクセスが実際に始まり、拒否やデバイスエラーも先に分かるようにしました。
- 「入力機器を更新」はカメラアクセスを確認してから一覧を取り直し、失敗理由も表示します。
- WindowsではQtの個別マイク許可状態が未対応なのに拒否と誤判定してプレビューを止める問題を修正しました。Windowsのデスクトップアプリ向けプライバシー設定を画面内で案内します。

## 更新

- 起動方式に対応して自動更新できる場合だけアプリ内の更新ボタンを出します。ソース実行など自動更新できない起動方式ではReleaseページを案内します。

## 対応環境

- macOS Apple silicon
- Windows 11 x64

Windows実機のカメラ、マイク、配信と自動更新、およびMac実機の配信チャット合成はこのビルド環境では実機確認していません。
