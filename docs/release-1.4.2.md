# たぬつな Studio 1.4.2

## 録画とV体の負荷を改善

- Windowsではカメラ追跡の映像を320×240・約15回/秒で解析し、V体追跡中のCPU負荷を抑えます。Macの追跡設定は従来どおりです。
- V体パネルが30回/秒で行っていた設定値の読み込みと状態表示の更新を抑え、収録や編集との競合を減らしました。
- 収録停止後のファイル確定を30秒で中断せず、収録時間に応じて最大10分まで待機します。途中で完了できなかった場合も、元データを保持して再開できます。
- 収録タイムアウト時の状態表示と警告表示が重複しないよう整理しました。

## 対応環境

- macOS Apple silicon
- Windows 11 x64

Windows実機でのカメラ追跡負荷と、長時間収録後の停止処理はこの配布物の作成環境では実機確認できていません。
