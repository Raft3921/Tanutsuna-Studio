# たぬつな Studio 0.9.11

## 編集を軽く、タイムラインを使いやすく

- タイムラインの波形表示データを再利用し、再描画時の余計な処理を減らしました。
- 新しい編集版は「メイン」レイヤーと下側の音声レイヤーから始まります。メインには動画・静止画・音声を置けます。映像レイヤーを追加するとメインの上に並びます。
- レイヤー名を「V1」「A1」から「メイン」「上レイヤー」「音声」に変更しました。

## 字幕ライブラリ

- 字幕を素材一覧と分け、動画ごとの `03-edit/subtitles` にSRTで保存します。
- 収録時に生成した字幕をライブラリへ取り込み、SRTファイルからの保存にも対応しました。
- 保存した字幕を選択して、または全てまとめて、編集可能な字幕クリップとしてタイムラインへ追加できます。追加操作はまとめて取り消せます。

作品や収録素材、設定は従来どおりアプリ本体とは別に保存されます。
