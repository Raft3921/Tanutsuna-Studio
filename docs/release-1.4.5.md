# たぬつな Studio 1.4.5

## 配信画面とシーン切り替え

- 配信プレビューを中央に置き、左に配信設定、右にYouTube LIVEチャットと視聴者数を表示します。
- 配信開始時はV体が回転・移動・縦変形するオープニングを表示し、ワイプでゲーム画面へ切り替えます。演出中はマイクを自動ミュートし、ゲーム画面に入るとオンにします。
- シーン切り替えウィンドウから「オープニング演出」「ゲーム画面」「離席中」を選べます。離席中はマイクをミュートします。
- 配信用の自然スタジオ背景を追加しました。画像は配信解像度に合わせて事前に縮小し、フレームごとの拡大縮小を避けます。

## YouTubeチャットと視聴者数

- YouTubeの配信URLを接続すると、アプリ内にライブチャットを表示します。登録した配信URLは次回のライブ画面で再接続します。
- 視聴者数の取得にはYouTube Data APIキーが必要です。キーはOSの資格情報ストアへ保存できます。
- 視聴者数が非公開の場合や、配信URL・APIキーを取得できない場合は、人数が表示されないことがあります。配信中の放送を自動検出するOAuth接続はまだ対応していません。

## テロップと位置調整

- 新しいテロップは入り・終わりのアニメなしで始まります。登録済みテンプレートの設定は保持されます。
- 編集画面と配信画面に位置・サイズのスライダーを追加しました。テロップ作成では選択したモーションキーをスライダーで調整できます。
- テロッププレビューの縮小画像を再利用し、連続したスライダー操作の再描画をまとめます。

## 対応環境

- macOS Apple silicon
- Windows 11 x64

Windows実機でのインストール、YouTube実配信、APIキーによる視聴者数表示は、この配布物の作成環境では確認していません。
