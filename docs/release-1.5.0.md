# たぬつな Studio 1.5.0 ご利用ガイド

## V調整画面でRaftのV体を操作

- 「完全版Vtuber」から顔に追従するFBXモデルと表情素材を取り込みました。
- V調整画面のプレビューとV体単体出力で同じモデルを表示します。
- 既存のカメラ追跡と手動調整を使い、頭の向き、口の開閉、あいうえお、瞬き、口幅・高さ、モデル回転を反映します。
- Three.jsとFBXLoaderを同梱し、モデル表示時のCDN接続を不要にしました。
- 「3Dモデルを保存」から元のFBXを保存できます。

モデルデータの利用・再配布は、提供元の利用条件に従ってください。

## 更新

1.4.14からの差分ZIPと各OSの完全版ZIPを配布できます。差分ZIPは対応する1.4.14からの更新に使用し、差分が利用できない場合は完全版へ切り替えてください。
